# Projeto AloiTubeManager

## Descrição

Gerenciador de canais do Youtube.

## Funcionalidades

- Autenticação com Google
- Listar vídeos
- Criar vídeos
- Atualizar vídeos
- Criar shorts
- Atualizar shorts
- Listar comentários de vídeos e shorts
- Responder comentários de vídeos e shorts
- Curtir comentários de vídeos e shorts
- Descurtir comentários de vídeos e shorts
- Categorizar comentários de vídeos e shorts
- Enviar lotes de respostas para comentários conceitualmente iguais
- Transcrever áudio de vídeos
- Gerar títulos, descrição, tags e prompts para criação de capas de vídeos, com base na transcrição

## Ferramentas

- Linguagem Python
- Framework FastAPI
- Banco de dados SQLite
- API do Youtube
- OAuth 2.0
- JWT
- Ollama (LLM's)
- Interface Desktop (windows, linux e mac)
- Painel de estatísticas que ainda vou definir

## Arquitetura

- Clean Architecture
- TDD
- Minimal API
- Banco de dados MySql
